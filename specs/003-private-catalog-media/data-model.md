# Private media data model
CatalogMedia: id; candidateId/sourceId RESTRICT FKs; sourcePolicyVersion; importKey8..100 ASCII letters/digits/_/-; inputHash SHA256 bytes+canonical metadata+recipe1; evidenceUrl HTTPS exact source host; evidenceRef1..500,creator1..200,attribution1..1000,alt1..300 trimmed chars; acquiredAt explicit ISO timestamp not future; originalHash/bytes/format/width/height; storageKey serverUUID; derivatives bounded JSON holding variant/hash/bytes/width/height/format; recipeVersion1; submittedById/createdAt; status READY_FOR_REVIEW/ACCEPTED/REJECTED; review note1..1000/time/actor; identityConfirmed boolean; withdrawnAt/withdrawnById. Unique(candidateId,importKey), index(candidateId,id). Actor IDs preserve history; audit supplies user relation. Source policies are immutable except revoke; version pinned.

Original file immutable original.bin; review-only preview.webp and thumbnail.webp. All files written exclusively under random owned directories, file modes0600/root0700 where supported. Original SHA256 retained; derivatives independently hashed. No bytes/proofs exposed through public paths. Metadata responses omit storageKey; derivative route chooses fixed allowlist, checks hash/length and sets private,no-store/nosniff headers. Derivatives strip EXIF/ICC after sRGB conversion; separate rights evidence retained. Orientation reflected in derivative dimensions, original dimensions retained as decoded source width/height.

Eligible preparation requires media accepted+identityConfirmed+not withdrawn; both image source and catalog fact source active/unexpired; source policy version unchanged; candidate accepted with fresh sale/fact observations. It is not a public publication permission by itself. Acceptance final; repeated same review/note/identity flag idempotent; different final decision conflicts. Withdrawal idempotent and irreversible in this slice. Rejection permitted after permission lapse.
